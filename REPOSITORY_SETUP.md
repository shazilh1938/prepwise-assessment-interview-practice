## Publication Checklist

1. Create a new **public** repository with the recommended name.
2. Do not initialise it with a README or licence; this package already contains both.
3. Upload or push the contents of this directory so `README.md` is at the repository root.
4. Set the repository description, website and topics above.
5. Enable **Issues** so the structured report forms work.
6. Enable secret scanning and push protection if available for the account.
7. In **Settings → Social preview**, upload `assets/prepwise-social-preview.png`.
8. Pin the repository on the relevant GitHub profile.
9. Add the final GitHub repository URL to the Prepwise About page or footer.
10. Request indexing of the GitHub repository URL in Google Search Console only if the property setup permits it; otherwise link to it from an already indexed Prepwise page and allow discovery.
11. Keep the repository active with genuine documentation updates rather than cosmetic commits.
